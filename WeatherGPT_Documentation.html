Project Overview

WeatherGPT is an AI-powered weather intelligence system trained on over 27 million real historical weather records. Users ask natural language questions like "Will it rain tomorrow?" and the system routes to the correct ML model.

Dataset: 27,621,770 rows from 1833 to present. Training city: Brussels, Belgium (69,347 rows).

ML Models

LSTM Neural Network

Temperature forecasting using 30-day sliding windows to predict 7-day trends.

Architecture2x LSTM + Dropout + Dense
Input30 days x 5 features
Output7-day temperature forecast
Train samples55,448
Val MAE0.14 (scaled)

XGBoost Classifier

Rain prediction with class balancing (scale_pos_weight=3) for imbalanced data.

API Endpoints

Base URL: http://127.0.0.1:8000

MethodEndpointDescription
GET/Health check
GET/ask?question={text}Intent detection
GET/predict/rain?month=&temp=&min_temp=&max_temp=&wind=Rain prediction
GET/predict/extreme?temp=&wind=&rain=Extreme weather
Example:
GET /ask?question=will it rain tomorrow
Response: {"intent": "rain_prediction", "status": "success"}

GET /predict/rain?month=7&temp=28&min_temp=22&max_temp=35&wind=25
Response: {"rain_probability": 60, "prediction": "rain"}

How to Run

Requirements: Python 3.12, minimum 4GB RAM, 5GB disk space.
1
Clone repository
git clone https://github.com/sampath-s07/weathergpt-ml.git
cd weathergpt-ml
2
Install dependencies
pip install fastapi uvicorn pandas numpy scikit-learn xgboost tensorflow joblib
3
Download dataset
Download "Global Weather Repository" from Kaggle. Place files in data/raw/ folder. (Not on GitHub - too large)
4
Run data cleaning
jupyter notebook  (then run 01_eda.ipynb)
5
Train models (optional)
Run in order: 02_lstm.ipynb, 03_xgboost.ipynb, 04_anomaly.ipynb, 05_bert.ipynb
6
Start API server
cd api
uvicorn main:app --reload
7
Open frontend
Open frontend/index.html in browser. Chat interface connects to API automatically.
